# 工程火种 / TorchLab

本地网页应用，使用 Python 3.10+ 标准库及 SQLite，无需安装额外依赖。

## 启动

双击 `start.bat`，保持窗口开启，然后在浏览器打开 http://127.0.0.1:8765 。

也可运行 `python server.py`。端口占用时运行 `python server.py --port 8766`，并使用相应地址。

## 部署到服务器

默认只绑定本机回环地址（`127.0.0.1`），仅本机可访问。部署到公网时使用 `--host` 参数：

```
python server.py --host 0.0.0.0 --port 8765
```

绑定到 `0.0.0.0`（或服务器网卡 IP）后，外网才能访问；此时不再限制请求的 Host 头，改为依赖同源 Origin 校验与 Cookie 的 `SameSite` 来防止跨站请求。建议在前面加一层 HTTPS 反向代理（如 Nginx/Caddy），并通过防火墙只开放需要的端口。

## 使用

网站默认打开学生首页。登录时选择学生端或工程师端，账号身份与所选入口必须一致。工程师登录后进入指导工作台。工程师仍可通过“浏览学生端”查看公共内容。

## 管理员

1. 启动网站后，打开 http://127.0.0.1:8765/#admin/setup 。
2. 打开本地 `data/admin-setup-key.txt`，复制初始化密钥并填入页面。
3. 设置管理员邮箱、称呼和密码。若使用已注册邮箱，须填写该账号的现有密码。
4. 创建成功后使用管理员入口登录。管理员可查看所有用户资料、邮箱、全部匹配申请与完整聊天记录，支持搜索和筛选；密码和登录令牌不会显示。管理员查看不会改变参与者的未读状态。

管理员初始化仅开放一次，普通注册不能获得管理员权限。初始化密钥属于本机文件，不包含在项目压缩包内。初始化后若管理员退出，可在登录弹窗选择“我是管理员”再次登录。管理入口为 http://127.0.0.1:8765/#admin 。

## 学生与工程师流程

1. 注册工程师账号，在个人资料里填写专业、从业年限、背景及指导方式，勾选开放预约。
2. 另开浏览器的无痕窗口，注册学生账号，从“寻找工程师”发送匹配申请。
3. 工程师在“我的咨询”接受申请，双方即可在同一项目中发送消息，页面每 3 秒更新。
4. 工程师可以结束咨询，完成的项目保留只读聊天记录。

包含首页、六个工程专业与详情、搜索与专业筛选、用户资料、匹配工作台、聊天和未读消息提示。每个咨询支持学生与工程师两个真实账号交流；不包含群聊、附件上传或视频通话。

## 数据与本地范围

数据保存在 `data/torchlab.sqlite3`。备份时先停止服务器，再复制整个 `data` 文件夹。密码使用 PBKDF2-SHA256 加盐哈希；登录会话使用 HttpOnly cookie。聊天接口在服务端检查双方身份及申请状态，第三个账号无法读取或发送消息。

服务仅绑定本机回环地址，不对外开放，也未使用 Sites 或上线。可以用不同浏览器/无痕窗口在同一电脑验证多个账号。跨设备访问需另行部署。

本地版的邮箱仅用于登录识别，未连接邮件验证或密码找回服务；工程师身份由本人声明，未进行资质认证。没有支付处理。列表初始为空，不添加虚构工程师或聊天内容。

## 验证

`python test_server.py` 在临时数据库中验证注册登录、权限隔离、匹配状态、消息与未读计数，不会改动正式数据。
